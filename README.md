# Profile Details App

A simple and responsive Profile Details application built using React and Vite.

## Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS

## Features

- Display user profile information
- Display profile picture
- Show user's name and email address
- Display user points
- Increase points using the + button
- Mobile-friendly user interface

## Project Preview

The application displays user profile information in a clean and simple mobile interface.
